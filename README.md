# Fibonacci Sequence in Python

## Overview
This project contains a Python program that generates the Fibonacci sequence for a specified number of terms.

## How It Works
- Takes the number of terms as input.
- Initializes the first two values as 0 and 1.
- Uses a loop to print each term.
- Updates the values to generate the next term.

## How to Run
Run `fibonacci.py` using Python and enter the desired number of terms.

## Example
**Input:** `7`

**Output:** `0 1 1 2 3 5 8`

## Learning Objective
To understand Python variables, user input, loops, and updating values to generate a sequence.
